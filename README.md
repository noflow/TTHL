# Tape To Tape Hockey League Website

This folder is generated by `league_manager.py build-website`.

Publish this folder as its own GitHub Pages repository for this league.

After changing the league config, rebuild this website folder from the main API tools repo.

To include teams from the API sheet, select **TTHL → Website Tools → Sync Teams**,
then **Build Website** and **Download Website ZIP**. Alternatively, check
**Sync teams from API first** when building. Upload the rebuilt package to this
repository. Editing the sheet alone does not update the team list embedded in
the website.

The source sheet's **Team List** tab supplies Website Name, Abbreviation,
Division, and Logo. Logo filenames must match the files in `images` exactly,
including capitalization. For this site, use `New York Rangers.png`,
`Pittsburgh Penguins.png`, and `vancouver canucks.png` (no spaces before `.png`).
